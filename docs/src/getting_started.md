# Getting started

The workshop uses a prepared editor and software environment. Start with the
[reference LOBSTER column](generated/00_reference_column.md): it introduces
the Oceananigans grid, the OceanBioME ecosystem, simulation setup and the
resulting figures in a single instructor-led example.

Next, the [grazing experiment](generated/01_grazing.md) changes one
biological parameter and compares the two simulations. The
[physics appendix](generated/physical_forcing.md) explains the light and
mixing conditions used by both examples.

For local installations, Python and Julia setup, quick tests and generating
your own figures, follow [Running the examples on your own system](running_locally.md).
