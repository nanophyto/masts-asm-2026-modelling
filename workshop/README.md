# MASTS ASM 2026 — Modelling workshop

**Begin with `01_OceanBioME/00_reference_column.jl`.** Open the file in Explorer,
then use **Julia: Execute File in REPL** to run the annual reference column.
Figures appear in the Julia Plot Pane in their creation order. Use the plot
history to revisit earlier figures; keep the same REPL for later exercises.

Next run **`01_OceanBioME/01_grazing.jl`** and compare the biology and carbon
export. The scripts use the real OceanBioME and Oceananigans model constructors.
Figures and diagnostics are saved in **`results/oceanbiome/`**; click a PNG in
Explorer to view it.

See [START_HERE.md](START_HERE.md) for terminal commands and additional guidance.
