# GOSML mixed-layer climatology: BATS and NABE

**Source:** NOAA PMEL Global Ocean Surface Mixed Layer Statistical Monthly Climatology (GOSML), Johnson and Lyman (2022), *JGR: Oceans*, doi:[10.1029/2021JC018219](https://doi.org/10.1029/2021JC018219).

This directory holds the small, offline reference product for the BATS/NABE workshop forcing comparison (PR2). The scientific figures in PR2B/2C use `gosml_mld_bats_nabe.csv`, generated by the reproducible PR2A script. Commit this small CSV and its metadata so every documentation build can regenerate figures offline.

## Prepare the observational reference

Use the **dedicated Conda environment** defined in `scripts/gosml-environment.yml`. From the repository root:

```bash
conda env create -f scripts/gosml-environment.yml
conda run -n masts-gosml python scripts/prepare_mld_climatology.py
```

This installs the GOSML data-preparation dependencies (`numpy`, `xarray`, `scipy`, `netcdf4`) in `masts-gosml`, independently of the general/base Python environment. The environment file uses `conda-forge` packages and Python 3.11. To refresh an existing environment after dependency changes, use `conda env update -f scripts/gosml-environment.yml --prune`.

The script downloads the five source NetCDFs once and caches them at `data/observations/raw/` (ignored by Git). If the server is unreachable, download the five files linked on [NOAA's GOSML site](https://www.pmel.noaa.gov/gosml/) into one directory and run:

```bash
conda run -n masts-gosml python scripts/prepare_mld_climatology.py --source-dir /path/to/gosml-netcdf
```

Two output files are generated:

- **`gosml_mld_bats_nabe.csv`**: 24 rows, one for each calendar month at BATS and NABE, containing requested/selected coordinates, their separation in kilometres, mean MLD, 5th/50th/95th percentile MLD (metres, positive-down), observed profile count, and effective summed mapping weights.
- **`gosml_mld_bats_nabe.metadata.json`**: extraction date, nearest-valid-ocean-cell selection, SHA-256 of the five NetCDF files, upstream URLs, depth-unit checks, and scientific reference.

**Selection:** BATS (31.7°N, 64.2°W) and NABE (47°N, 20°W). The nearest grid cell with all 12 physically valid monthly values and mapping support is used. The maximum selection distance defaults to 350 km and can be reduced with `--max-distance-km`. The script raises an error when a complete valid series cannot be found, rather than inventing observations. It also rejects missing/duplicated months, invalid units, and inverted depth percentiles.

**Interpretation:** The GOSML 5th–95th percentile interval describes the distribution of observed MLD, **not** uncertainty on the climatological mean. GOSML combines Argo mixed-layer estimates using spatial, temporal and bathymetric weighting; the original paper specifies the Holte–Talley density algorithm. The original gridded NetCDF files are distributed by NOAA for non-commercial use. Cite Johnson and Lyman (2022) in plots and reuse.

## Compare observed and prescribed forcing (PR2B/2C)

From the repository root, after extraction:

```bash
julia --threads=1 --project=oceanbiome scripts/plot_mld_comparison.jl
```

The script calls the existing Julia station-specific `mixed_layer_depth(station, t)`
functions (no duplicated Python forcing code) and saves:

- `outputs/oceanbiome/mld_comparison/gosml_mld_comparison.png`: side-by-side BATS/NABE observed monthly mean, median and 5th–95th percentiles against the prescribed daily forcing, with positive-down depth and the 300 m domain limit.
- `outputs/oceanbiome/mld_comparison/gosml_mld_summary.md`: calendar-month means, annual mean, winter maximum, monthly mean bias and RMSE. Model-minus-observed bias is positive when prescribed mixing is deeper.

Full documentation builds regenerate the figure and summary from the checked-in CSV, including when `DOCS_REUSE_RESULTS=true`. No NetCDF download or Conda execution occurs during a documentation build.

```bash
julia --threads=1 --project=docs docs/make.jl
```

The observational product is currently generated by your data-preparation workflow; it is deliberately not substituted with invented values. Before running the full docs build on a clean checkout, generate and commit the observational CSV/metadata from the verified GOSML sources.

## Offline verification

```bash
conda run -n masts-gosml python -m unittest discover -s scripts -p 'test_prepare_mld_climatology.py' -v
```

Tests generate tiny synthetic NetCDF files and never download data. They check month order, longitude conventions, reversed coordinate order, validity-based nearest-neighbour selection, percentile consistency, depth units, selection distance and file hashes.

## Scope

PR2A provides verified observational extraction and provenance; PR2B/2C provide the model comparison, quantitative evaluation and automatically regenerated documentation figure. A separate pilot cycle can use the observed curve to assess whether physical parameter adjustments improve seasonal timing and biology.
